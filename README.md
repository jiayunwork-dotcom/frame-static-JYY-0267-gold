# frame-static

平面刚架静力求解器。提交节点坐标、杆件截面与荷载，后端用**直接刚度法**组装总体方程，解出节点位移，再回代杆端力与支座反力。

## 输入

JSON 模型：

```json
{
  "nodes":    [{ "id": "A", "x": 0, "y": 0, "support": "fixed" }],
  "elements": [{ "from": "A", "to": "B", "E": 2.1e11, "A": 0.01, "I": 8e-5, "dist": { "q": 0 } }],
  "loads":    [{ "node": "B", "fx": -50, "fy": 0, "mz": 0 }]
}
```

- 节点：`x`/`y` 平面坐标；约束可用布尔数组 `restraint:[ux,uy,theta]` 或符号 `support`（`pin` 铰支 / `fixed` 固支 / `roller-x` 滑动）。
- 杆件：两端节点、`E` 弹性模量、`A` 截面积、`I` 惯性矩；可选 `dist.q` 为局部坐标竖向均布荷载（向下为正）。
- 荷载：节点集中力/力矩；杆件均布荷载写为杆件的 `dist`。

## 输出

- 各节点位移 `ux`/`uy`/`theta`
- 各杆两端局部轴力 `Ni`/`Nj`、剪力 `Vi`/`Vj`、弯矩 `Mi`/`Mj`
- 支座反力（仅约束自由度）

交叉规则：全部支座反力与外荷载在整体坐标下主矢、主矩代数和为零；每根杆两端轴力反向等值；刚节点处邻杆端力与外荷载平衡。矩阵奇异（机构、约束不足、重复约束）返回错误而非 NaN。

## 运行

Web 求解器（含可交互前端）：

```bash
go run . -http :8080
# 打开 http://localhost:8080 ，加载示例后点「计算」
```

命令行（读 JSON 文件或 stdin，输出求解 JSON）：

```bash
go run . example/portal.json
cat model.json | go run .
```

非法模型、奇异结构会返回非零退出与可读错误。

## 方法

约束采用**划行划列**消去（仅保留自由自由度求解），全程不引入罚刚度。单元刚度在局部坐标成形（轴力 + 弯曲 6×6），经方向余弦转到总体坐标组装；位移解出后杆端力由局部刚度 × 局部位移 + 固端力得到。求解使用带部分主元的高斯消元。

纯标准库实现，无第三方依赖。
